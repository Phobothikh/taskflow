# TASKFLOW — Proje tanıtımı

## Amaç

Yazılım ekibinin görevlerini takip edebileceği bir REST API geliştirmek. Proje, backend eğitiminde işlenen Node.js, Express, routing, CRUD ve middleware konularını uygular.

## Senaryo

Şirket içinde projeler ve görevler dağınık ilerliyor; ekip tek bir API üzerinden görev açmak, atamak ve durum güncellemek istiyor. TASKFLOW bu API katmanını sağlar.

## Şu anki kapsam

- Görev ekleme, listeleme, detay, güncelleme, silme
- İstek günlüğü (method, adres, zaman)
- JSON dosyada veri saklama
- E-posta ile giriş, üye ve admin oturumu
- Günlük rapor, ekip takibi ve tarayıcı paneli

## Teknoloji

Node.js, Express.js
