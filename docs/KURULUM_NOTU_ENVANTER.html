1. Proje nedir?

TASKFLOW, Node.js ve Express ile yazılmış bir REST API projesidir. Görev CRUD, istek günlüğü (logger middleware) ve JSON dosya tabanlı veri saklama içerir. Tarayıcı paneli ve Postman koleksiyonu repoda mevcuttur.

2. Gereksinimler

  • Node.js 18 veya üzeri
  • npm (Node ile gelir)
  • İsteğe bağlı: Postman (API testi)

3. Projeyi indirme

Git ile klonlama (önerilen):

git clone https://github.com/Phobothikh/taskflow.git
cd taskflow

Alternatif: GitHub → Code → Download ZIP → klasörü aç → terminalde taskflow dizinine gir.

4. Bağımlılıkları kurma

npm install

Bağımlılıklar package.json ve package-lock.json dosyalarından yüklenir (Express vb.).

5. Sunucuyu çalıştırma

Geliştirme (dosya değişince otomatik yeniden başlar):

npm run dev

Tek seferlik çalıştırma:

npm start

Varsayılan adres: http://localhost:3000

Port doluysa (PowerShell):

$env:PORT=3010; npm run dev

6. Kurulumun doğrulanması

7. Postman

Sunucu açıkken Postman → Import:

  • postman/TASKFLOW.postman_collection.json
  • postman/TASKFLOW-Yerel.postman_environment.json

Ortam: TASKFLOW Yerel. Adım adım: docs/POSTMAN.md. CRUD ekran görüntüleri: docs/ekran-goruntuleri/.

8. Klasör yapısı (özet)

9. Sorun giderme

  • Could not connect / bağlanamıyor: npm run dev çalışıyor mu?
  • Port kullanımda: PORT=3010 ile deneyin veya 3000’i kullanan uygulamayı kapatın.
  • npm install hatası: Node sürümünü kontrol edin (18+).
