# Veri modeli — Görev

Veriler `data/gorevler.json` içinde tutulur.

| Alan | Açıklama |
|------|----------|
| id | Benzersiz kimlik |
| baslik | Görev adı |
| aciklama | Detay |
| oncelik | dusuk / orta / yuksek / acil |
| durum | beklemede / devam_ediyor / tamamlandi |
| atanan | Görevin atandığı kişi (e-posta veya isim) |
| olusturulma | Kayıt zamanı |
| guncellenme | Son değişiklik zamanı |
